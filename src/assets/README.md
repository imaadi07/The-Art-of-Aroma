# Assets Directory

This directory houses static visual and audio assets for "THE ART OF AROMA":

- `images/`: High-resolution editorial photography of incense sticks, holders, burners, and packaging.
- `models/`: Optimized 3D assets (GLTF / GLB) compressed via Draco or meshopt for low-bandwidth devices.
- `textures/`: Environment maps (.hdr/.exr) and PBR materials.
- `audio/`: Ambient ceremonial soundtrack and subtle strike sound effects.
